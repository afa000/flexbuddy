## Current behavior

The Spring server extracts OCR with Tess4J, parses fields, translates warning messages and queries the signed-in
driver's blocks for duplicates. Android sends screenshots to the server and keeps offline screenshots waiting.
ShiftScreenshotParser and ImportWarningRules depend on Messages.current as well as Spring annotations; removing
annotations alone is insufficient. ScheduledShiftMatcher also owns repository access, station matching,
cross-midnight handling, overlap comparison, classification and translated duplicate descriptions.

Render builds with flexbuddy/ as its Docker context. The app POM is a Spring Boot executable JAR build, not a
reactor. Existing local and CI checks invoke Maven from flexbuddy/.

OcrSampleAccuracyTest currently measures five fields (station, date, start, end, pay), excluding tips. It requires
private local samples and labels. Its existing results cannot establish six-field phone parity.

## Required behavior

### Plain Java library

- Add flexbuddy/import-core/ with coordinates com.angel:flexbuddy-import-core:0.1.0, a normal thin Maven JAR.
  The owner approved this internal dependency on November 14, 2026. Add no external runtime dependencies.
- Put the shared implementation in a dedicated com.angel.flexbuddy.importcore package. Include immutable OCR and
  parsed-result types, confidence, parsing context, warning descriptors, parser, warning rules and pure matching
  inputs/results. Use no Spring, persistence, server translation helper, Android, AWT, Tess4J, file/network access
  or global clock/locale state. Dates and OCR text are explicit inputs; amounts remain BigDecimal.
- Warning descriptors expose existing code, severity, field and message key. They contain no translated text.
  Preserve warning ordering, confidence thresholds, year inference, base-pay/tips distinction and rounding.
- Extract station matching, overnight intervals, overlap threshold and duplicate classification into pure rules.
  Keep repository queries, ownership, eligible statuses and localized descriptions in the server adapter.
  Preserve the existing previous-day search window and all current edge-case behavior; do not fix unrelated rules.
- Keep existing server classes and public signatures as thin adapters where necessary, so their tests and callers
  remain unchanged. Translate descriptors at the server boundary using the request locale, including parser-generated
  year-rollover warnings. Never expose a message key in place of current website/API warning text.
- One implementation of each business rule: adapters map values and delegate; do not retain a copied parser or
  second overlap algorithm in the application.
- Verify bytecode/API compatibility with the Android app's Java 21 toolchain and minimum SDK 26 in the subsequent
  app task. Avoid introducing Java APIs unavailable there without identifying required desugaring first.

enter the artifact. Preserve explicit completion decisions and server duplicate checks. Shared objects contain no
database entities. No migration or backup format change is permitted.
