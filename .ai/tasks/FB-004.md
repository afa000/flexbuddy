# Task: FB-004 - Take the October 2026 Tomcat and Java security fixes

Status: Ready for implementation

## Objective

Apache disclosed eight Tomcat flaws on October 20 2026, Oracle and OpenJDK shipped the October Java patches on October
20 and an out-of-band Java fix on October 21. FlexBuddy runs a Tomcat version inside the affected range and a Java
image built before those patches. None of the flaws is reachable with FlexBuddy's current settings, but the next
setting change could expose one, so production should run the fixed versions.

## Current behavior

Checked against `origin/main` at 6e03dd7.

- `flexbuddy/pom.xml` uses `spring-boot-starter-parent` 4.1.1. Its managed versions are Tomcat 11.0.24, Spring
  Framework 7.0.9, Spring Security 7.1.1, Hibernate 7.4.5, Jackson 3.1.5 and the PostgreSQL driver 42.7.13
  (`mvnw dependency:list`).
- **Tomcat 11.0.24 is affected** by CVE-2026-101356 (HTTP/2 request and response mix-up after an error in async
  processing, Important, 11.0.22 to 11.0.26). The same release fixes CVE-2026-101296 (JNDIRealm accepts a wrong
  password with non-GSSAPI SASL) and CVE-2026-103119 (AJP response mix-up). All are fixed in 11.0.27.
- **None is reachable today.** `application.properties` doesn't set `server.http2.enabled`, nothing in
  `src/main` adds a connector, an AJP protocol or a realm, and Render talks plain HTTP/1.1 to the container.
- **The Spring advisories in the news are already fixed.** CVE-2026-41707 (DPoP replay), CVE-2026-47841 (WebAuthn
  verification) and CVE-2026-47842 (AES/CBC fixed IV) are fixed in Spring Security 7.1.1, which FlexBuddy runs. The
  app uses none of DPoP, WebAuthn or CBC: `TwoFactorSecretCipher` uses `Encryptors.delux`, which is AES/GCM.
  CVE-2026-40992 (mail hostname check) affects Boot 4.0.x and 3.x only.
- **The PostgreSQL driver flaws need settings FlexBuddy doesn't use.** CVE-2026-107314 needs `requireAuth`, which
  isn't set.
- **The Java runtime is pre-October.** `flexbuddy/Dockerfile` runs on `eclipse-temurin:21-jre-jammy`. Docker Hub
  last updated that tag on October 17 2026, before Temurin 21.0.13 (released October 22). Each Render deploy pulls
  the tag again, so the Java version only changes when the tag is updated and the app is redeployed.

## Required behavior

1. **Spring Boot:** in `flexbuddy/pom.xml`, change the `spring-boot-starter-parent` version from `4.1.1` to `4.1.2`
   (published October 22 2026). That one line moves Tomcat to 11.0.27, Spring Framework to 7.0.10, Spring Security to
   7.1.2, Hibernate to 7.4.13, Jackson to 3.1.7 and the PostgreSQL driver to 42.7.14. Change no other dependency.
2. **Java:** leave the `Dockerfile` as it is. The floating `21-jre-jammy` tag picks up the patched Java on the next
   build after Docker Hub updates it. Before merging, check whether it has updated:
   `docker run --rm eclipse-temurin:21-jre-jammy java -version` should print 21.0.13 or later, or Docker Hub's
   "last pushed" for the tag should be later than October 22 2026. If it hasn't updated yet, merge anyway for the
   Tomcat fix, and tell the owner to redeploy once it has (step 4 of the production checks).

## Out of scope

- Pinning the base image to a version or digest. See the open questions.
- Moving to Spring Boot 4.2 (still a release candidate), Java 25, or a newer Ubuntu base.
- Turning on HTTP/2 or changing any other server, mail or security setting.
- The Android wrapper. It runs in the phone's Chrome, which updates through the Play Store.
- Leptonica 1.87.0 and Tesseract 5.5.3. No October advisory was found for either.

## Security and regression risks

- **Sign-in:** Spring Security moves 7.1.1 → 7.1.2, a patch release. The sign-in, two-step, Google and rate-limit
  tests (`GoogleSignInIntegrationTest`, `AttemptLimiterTest`, `ClientAddressFilterTest`, `TotpTest`) all pass on the
  upgrade.
- **Database:** Hibernate and the driver change patch versions only. There's no migration, and CI's PostgreSQL 18
  migration test covers the schema.
- **Backup and restore:** Jackson 3.1.5 → 3.1.7 is a patch release, and the backup and restore tests pass.
- **Two-step secrets:** `FLEXBUDDY_TWO_FACTOR_KEY` and `Encryptors.delux` are unchanged, so stored authenticator
  secrets still decrypt (`TwoFactorSecretCipherTest`).
- **Memory:** the Dockerfile's memory settings (`MALLOC_ARENA_MAX`, serial GC, C1) are unchanged. A new Java patch
  release doesn't change the native OCR memory.
- **Catalogs, earnings rules and Android:** untouched.

## Open questions

1. **Pin the Java image?** The floating tag patches itself on any deploy, but you can't see which Java a build used
   without reading the log. Pinning, such as `eclipse-temurin:21.0.13_9-jre-jammy`, makes it visible and repeatable,
   but every Java patch would then need a commit. The planner recommends keeping the floating tag and checking the
   startup log after deploys.
2. **The out-of-band Java fix (CVE-2026-91403, October 21)** concerns trusted certificate authorities. It matters for
   FlexBuddy's outgoing HTTPS to Google sign-in, Gmail and push services. Secondary sources disagree on whether
   Temurin 21.0.13+9 includes it. Check the OpenJDK advisory for 2026-10-21 against the Java version in the startup
   log. If it isn't included, redeploy once a Temurin build with the fix is out.
